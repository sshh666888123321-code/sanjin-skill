# 投放笔记赛跑与咨询质量反馈

## R — 原文 (Reading)

> 我的聚光投放策略，是笔记赛跑。筛选优质笔记建立智投赛跑，再次细筛更高转化低成本的笔记加大投放力度。
>
> — 叁斤，084｜小红书聚光投放，出境游月营收770万投放复盘

## I — 方法论骨架 (Interpretation)

把投放当成连续实验，而不是一次押注。
先让同一目标下的多条候选内容以小预算并行，确保每条的目标、受众和预算可比。
第一轮看点击等前端信号，第二轮必须回读咨询内容，确认是否为目标客户。
继续把有效咨询、成交率、客单和利润纳入判断，不能让低质便宜线索掩盖亏损。
停掉低质量样本，把预算集中到既能带来有效客户又能承受成本的笔记。
放量后继续监控质量，质量下降就回退预算或换样本。

## A1 — 书中的应用 (Past Application)

### 案例 1: 出境游笔记赛跑
- **问题**: 多条投放内容表现不同，无法凭经验决定预算。
- **方法论的使用**: 先用智投让笔记并行竞争，再筛高转化、低成本样本。
- **结论**: 预算应由可比实验和后端结果共同决定。
- **结果**: 作者以该策略支持出境游投放复盘，文中报告月营收 770 万。

### 案例 2: 低价咨询量与成交错位
- **问题**: 某些笔记咨询多、成本低，但客户质量差。
- **方法论的使用**: 回看咨询用户质量和转化率，而不接受表面成本的胜出。
- **结论**: 低 CPC 不是放量理由。
- **结果**: 低质量笔记被判定为不值得继续投。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill?

1. 有多条广告素材，想用小预算找出应加码的样本。
2. 点击或私信成本很好看，但销售反馈成交差。
3. 需要建立“投放数据—咨询质量—成交利润”的回传表。

### 语言信号 (用户的话里出现这些就应激活)

- “哪条笔记值得加预算？ / which ad should I scale?”
- “咨询成本很低，但为什么没有成交？”
- “帮我按有效线索和利润筛广告。”

### 与相邻 skill 的区分

- 与 `reverse-funnel-scaling` 的区别：本 skill 比较投放素材和后端线索质量；后者决定产品先向哪层人群扩张。
- 与 `periodic-review-controlled-variable-adjustment` 的区别：本 skill 聚焦付费素材赛跑；后者处理更广泛的周期变量复盘。

## E — 可执行步骤 (Execution)

1. **建立可比样本**：为每条笔记记录目标、受众、预算、时间窗和素材版本；完成标准是至少 3 条样本可横向比较。
2. **分层回传质量**：记录点击、咨询内容、有效咨询、成交、收入、成本和利润；若无法取得后端质量，判定为“不可放量”而非按前端加码。
3. **调整预算并复测**：停掉低质或亏损样本，把预算小步集中到优胜样本；完成标准是放量后质量和利润仍达预设门槛。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- 用户还没有明确产品、人群或成交定义，只是在泛泛追求曝光。
- 单条自然内容没有可比样本，不能把偶然波动当作投放结论。

### 作者在书中警告的失败模式

- 只看咨询量和低成本，不监控咨询质量与成交。
- 只看点赞、点击等表面指标就持续加预算。

### 作者的盲点 / 时代局限

- 投放平台、归因窗口和审核规则会变化；案例收入不能直接外推当前回报。

### 容易混淆的邻近方法论

- 不是“预算平均撒开后等待爆款”，而是带后端质量门的受控实验。
